# swaco

A small, extensible agent core written in Swift.

Swaco gives any iOS or macOS app agentic capability with a minimal footprint:
a single agent core, one voice for any model, and a way to shape behaviour
from the outside without growing the core. No UI, no bundled tools, no
third-party dependencies.

Start with the [philosophy](PHILOSOPHY.md). It sits above every other decision
in this project.
