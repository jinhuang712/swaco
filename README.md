# swaco

A small, extensible agent core written in Swift.

Swaco is responsible for making an agent work correctly inside an iOS app.
The app is responsible for deciding what that agent is as a product.

Swaco gives any iOS app agentic capability with a minimal footprint: a single
agent core, one voice for any model, and a way to shape behaviour from the
outside without growing the core. No UI, no bundled tools, no third-party
dependencies.
