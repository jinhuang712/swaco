# swaco

A small, extensible agent core written in Swift.

Swaco gives any iOS or macOS app agentic capability with a minimal footprint:
one agent loop, a unified provider layer, and an extension mechanism for
changing behaviour without growing the core. No UI, no bundled tools, no
third-party dependencies.

Start with the [design philosophy](PHILOSOPHY.md). It is the basis for every
decision in this project.

Requires iOS 26 / macOS 26 and Swift 6.2.
